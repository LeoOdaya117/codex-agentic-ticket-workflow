# Install prompt

Install this Agentic Ticket Lifecycle kit into the current target repository. First read `CODEX_INSTALL.md` and `README.md`. Inspect target `AGENTS.md`, skills, registered agents, `.codex/config.toml`, ticket directories, and working-tree changes. Run the installer without `--force`, then integrate `AGENTS.ticket-addon.md` conservatively if `AGENTS.md` already exists. Preserve conflicts and report them. Run discovery and included tests. Do not create or process a real project ticket during installation. Use the existing Codex login; do not ask for an API key.
