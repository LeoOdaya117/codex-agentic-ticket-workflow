# Process ticket prompt

Use `$process-ticket [TICKET-ID]` to investigate, plan, implement, review, and QA this ticket in its dedicated Git worktree and `codex/<TICKET-ID>` branch. Follow the target repository's `AGENTS.md` and conventions. Preserve unrelated changes, discover the team, record acceptance progress only when supported by evidence, and report exact test outcomes. After passing QA, commit and push the branch, create or update the pull request, and record its URL with the branch and commit in the ticket. Stop at `Ready for Human Verification` with the PR open for human testing. Never merge or close the PR; the human decides when to merge.
